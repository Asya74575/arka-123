# Шрифты

Только локальные файлы WOFF2 с кириллицей и открытой лицензией (SIL Open Font License 1.1). Рядом — файл лицензии `OFL-<имя>.txt`. Подключение `@font-face` — в tokens.css. Ссылки на fonts.googleapis.com и другие внешние шрифтовые сервисы запрещены.

Файлы взяты из пакетов `@fontsource/*` 5.3.0 (npm), в них латиница и кириллица разделены.

**Пара сайта (выбор владельца 2026-10-11, шрифты логотипа):** Manrope 700 — заголовки (`manrope-*-700-normal`), Roboto 400 / 600 / 700 — текст (`roboto-*`, лицензия OFL-roboto.txt). У этих @font-face в tokens.css есть `unicode-range`: русский текст грузит только кириллический файл.

Кандидаты для сравнения (drafts/fonts.html, drafts/fonts-2.html и другие черновики), до выбора пары:
- Cormorant (500, 600) — заголовки; Manrope (400, 500, 600) — текст.
- Unbounded (500, 600) — заголовки; Commissioner (400, 500, 600) — текст.
- Ysabeau Office (500, 600) — заголовки; Manrope — текст.

Сайт их больше не грузит (браузер скачивает шрифт, только когда он используется), но черновики в drafts/ ссылаются на эти файлы. Удалить лишние файлы, их @font-face и лицензии — перед публикацией (/publish), когда черновики больше не нужны.
