# АРКА 123

Одностраничный сайт зала для мастер-классов и семинаров в Минске: лофт 123 м² с двумя арочными окнами напротив Национальной библиотеки. Сделан как тестовое задание для портфолио. Компания, цены, отзывы и контакты — условные.

Сайт: https://asya74575.github.io/arka-123/

## Что на странице

- заставка с анимацией логотипа;
- видео зала на первом экране и видеопрогулка с фирменным персонажем — Солнечным зайчиком;
- интерактивная 3D-модель зала по плану помещения: поворот, масштаб, четыре расстановки мебели;
- 3D-карта района: камера летит по маршруту от метро «Восток» за прокруткой;
- форматы и цены, галерея, отзывы, частые вопросы, форма аренды.

Форма демонстрационная: заявки никуда не отправляются, и после отправки страница прямо об этом говорит. Телефон и почта — заглушки.

## Как устроено

HTML, CSS и JavaScript без сборки и фреймворков. Страница открывается и двойным щелчком по `index.html`.

- `index.html` — главная; `404.html` — страница «не найдено»; `legal/` — политика конфиденциальности, согласие на обработку данных, cookie;
- `assets/` — стили, скрипты, шрифты и библиотеки;
- `img/`, `video/` — изображения и видео.

## Библиотеки и данные

- Manrope, Roboto, Oswald — SIL Open Font License 1.1, лицензии лежат рядом с файлами в `assets/fonts`;
- Buyan (Yu Type) — заголовки. Шрифт коммерческий: для своих проектов покупайте его у автора на MyFonts.

## Изображения и видео

Фото зала и логотип — материалы тестового задания. Видео и фирменный персонаж созданы с помощью нейросетей. 3D-модель зала и карта района — собственная работа.
